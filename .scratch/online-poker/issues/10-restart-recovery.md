# 10: 重启恢复牌局与原期限

Status: ready-for-agent
Type: implementation
Spec: [在线德州扑克首版规格](../spec.md)
Blocked by: [09](09-storage-failure-commit-resolution.md)
Primary acceptance cases: AC30故障恢复部分、AC33、AC36–AC38、AC40

## What to build

应用重启后同一身份读回原牌、底池、筹码和结果；已有期限不延长，此前在线者从成功恢复起获得一次连接宽限，页面呈现恢复后的权威状态。

## Acceptance criteria

- [ ] 余额99跟注10在提交前/后分别停止进程；恢复只出现完整旧99/旧池/旧行动或新89/池增10/下一行动，原牌序保持。
- [ ] 未结算恢复固定参赛身份、牌序、投入和期限；已结算不重复派奖，不清池/退款/重发100，不重复05补给。
- [ ] 原已过期期限按截止时间处理，同刻离房优先；不补造停机期间尚未创建回合，新行动从实际推进起计30秒。
- [ ] 此前在线者从成功恢复起获连接宽限30秒；已断线者保持旧期限；连接宽限不延长原行动期限，故障宽限期间拒绝开局。
- [ ] 仅数据库故障且控制连接仍在不额外创建宽限；恢复与新页接管不恢复已失效控制权或撤销已生效弃牌/结算。
- [ ] 损坏、不兼容或筹码不一致存档显示故障并停房间，不猜赢家、清池、退款或重发100。
- [ ] 真实数据库+进程重启+浏览器重连验证，恢复先解决09提交结果不明，页面不以重新洗牌/恢复上局余额代替。

## Public test boundaries

规格范围：D7 故障计时、D8–D9；案例见[可追踪验收案例](../spec.md#可追踪验收案例)。

- 公开启动恢复/牌局命令/按身份视图，真实PostgreSQL与受控时间、固定牌序；应用进程故障前后验证完整旧或新状态。
- 真实HTTP/WebSocket重连验证原身份、故障提示、连接宽限和已有行动期限；不直接断言内部快照字段布局。
