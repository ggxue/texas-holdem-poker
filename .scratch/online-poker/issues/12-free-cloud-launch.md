# 12: 免费云上线与整体验收

Status: ready-for-agent
Type: implementation
Spec: [在线德州扑克首版规格](../spec.md)
Blocked by: [11](11-process-ownership.md)
Primary acceptance cases: AC41–AC43

## What to build

在Render Free + Neon Free提供可访问的HTTPS/WSS游戏。电脑/手机和两个不同浏览器完成对战、结算和下一局；冷启动、重部署和数据库恢复后原身份与存档连续。

## Acceptance criteria

- [ ] 使用research查届时当前官方资料并核对实际控制台：Render Hobby+Free、NeonFree、无支付方式/付费资源，平台免费域名及HTTPS/WSS。
- [ ] 实际一名真人+机器人、两名真人+机器人能完成完整牌局并由房主开下一局；电脑/手机合法动作、扣款、倒计时与结果可操作。
- [ ] 实际休眠唤醒、重部署和WebSocket重连沿用原身份；数据库暂停/恢复执行故障停止及期限规则，已提交余额/牌局跨应用重启保留。
- [ ] 记录实际额度、地域、冷启动与数据保留验证，不用试用余额代替免费计划，不以应用本地盘当存档，不新增保活强行常驻。
- [ ] 汇总AC01–AC43的自动化/浏览器/云证据，补足AC41–AC43及AC07–AC40云上组合场景；任何失败或缺工具明确记录，不标整体done。
- [ ] 复核先前全部中文逐行逻辑注释、暗牌权限、去重、单池/全押/退出、存档原子性和旧进程隔离，不把文档校验当游戏验收。

## Public test boundaries

规格范围：D1、D9–D10；全部AC云上组合验收；案例见[可追踪验收案例](../spec.md#可追踪验收案例)。

- 实际Render/Neon、HTTPS/WSS、两个浏览器身份及同身份接管、电脑/手机完成可复现端到端验收。
- 复用前票公开seam与真实数据库证据；真实休眠/重启/故障场景独立留证，不重新造一套私有结构测试。
