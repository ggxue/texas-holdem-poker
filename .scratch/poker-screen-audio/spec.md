## Problem Statement

用户第二轮测试发现信息不能稳定集中在一屏，玩家面前缺少实体筹码，
动作、环节与本人机会缺少中文声音提示。用户审看原型后已选择深红赌场主题的
B2 · 桌沿席位，要求开发真实可用版本并上线。

## Solution

将已选B2接入真实单房间：左侧十类牌型参考，中央固定六席、公共牌和独立底池，
下方本人合法操作，右侧完整结算。每个占用席面前摆表示可用余额的筹码堆。
采用深红台呢、暗皮革厚桌沿、仿古黄铜铭牌和下注按钮，纸牌/筹码具有厚度、纹理和阴影。
用服务器确认的公开事件触发普通话女声播报；本人行动提醒优先，语音不影响牌局计时。
按既有免费单进程Go云部署方向上线，并记录实际可验证的部署条件和限制。

## User Stories

1. 作为电脑玩家，我希望1280×720可用视口、100%缩放时全部信息一屏可见，以便无需滚动查找。
2. 作为玩家，我希望页面和面板都不靠滚动/折叠/全页缩小塞入信息，以便持续看清局面。
3. 作为玩家，我希望主文字和按钮至少14px、紧凑参考至少12px，以便阅读。
4. 作为满员参赛者，我希望六人的结算完整可见，以便核对奖项与牌力。
5. 作为玩家，我希望以“玩家1–5”及“机器人”称呼各席，以便避免“真人”的叫法。
6. 作为玩家，我希望固定座位不随本人身份旋转，以便找到每个玩家。
7. 作为玩家，我希望自己的席位标“你”和暖金框，以便识别本人。
8. 作为玩家，我希望行动者额外用象牙白外框、柔光和状态文字，以便识别当前等待对象。
9. 作为当前本人，我希望两种标记同时可见，以便确认轮到自己。
10. 作为玩家，我希望每个占用席的余额筹码摆在面向桌心的台面，以便像实体牌桌一样归属清楚。
11. 作为玩家，我希望筹码堆与准确可用余额和投入分别显示，以便不混同已下注和剩余金额。
12. 作为玩家，我希望堆大小粗略变化并限高，以便金额变化可感知且不遮挡信息。
13. 作为余额为0的玩家，我希望堆消失但0chips和实际全押状态保留，以便理解资格。
14. 作为重新入房的玩家，我希望余额设100时筹码堆更新但既有全押状态保持，以便符合原规则。
15. 作为等待下一局或已弃牌玩家，我希望占用席仍显示自己的余额筹码，以便查看钱包。
16. 作为短暂掉线玩家，我希望筹码保留但弱化，以便他人了解连接状态。
17. 作为玩家，我希望空席不显示虚假手牌或筹码，以便看到实际占座情况。
18. 作为玩家，我希望中央底池保持独立筹码堆及准确chips数字，以便核对投入。
19. 作为玩家，我希望结算底池归零隐藏堆并显示已分配金额，以便理解派奖。
20. 作为玩家，我希望真实赌场风格下纸牌角标、花色、细纹牌背仍清晰，以便辨牌。
21. 作为玩家，我希望黄铜下注按钮有材质和按下反馈，以便识别可操作道具。
22. 作为玩家，我希望操作只来自服务端合法动作，显示真实扣款及不足全押，以便正确行动。
23. 作为玩家，我希望提交、错误、重连、接管及退出状态可见，以便不猜测动作是否成功。
24. 作为玩家，我希望只看到服务器允许公开的手牌/牌型/最佳五张，以便保留隐私。
25. 作为手机玩家，我希望纵向可读可操作且没有横向溢出，以便继续参与。
26. 作为玩家，我希望所有确认的过牌/下注/跟注/弃牌播报行动者、实际金额和全押，以便听懂变化。
27. 作为玩家，我希望自动超时动作说明“超时”，以便区别主动选择。
28. 作为玩家，我希望开局、发手牌、翻牌、转牌、河牌、摊牌和结算都有短中文播报，以便跟上流程。
29. 作为玩家，我希望结算播报全部赢家及各自金额，以便了解分配。
30. 作为玩家，我希望入房/离房/掉线/回来/房主交接/机器人思考均有短播报，以便了解房间。
31. 作为本人，我希望每个新行动机会播一次“轮到你出牌”，以便及时行动。
32. 作为仍未行动的本人，我希望剩10秒再提醒一次且不逐秒念，以便减少干扰。
33. 作为玩家，我希望本人提醒打断并清掉旧队列，以便声音及时且不延迟服务器计时。
34. 作为玩家，我希望顶栏启用/静音/音量默认60%并记住偏好，以便控制全部声音。
35. 作为玩家，我希望播放受浏览器限制时出现可见恢复入口，以便有机会重启声音。
36. 作为回来的玩家，我希望刷新/重连/恢复声音/后台返回不补历史，仅提示当前本人剩余时间，以便不误听过期信息。
37. 作为玩家，我希望声音失败时游戏仍可操作，以便继续游戏。
38. 作为玩家，我希望知晓后台/锁屏不能保证提醒，以便不依赖必达声音。
39. 作为用户，我希望免费HTTPS/WSS单实例上线，并记录真实验证结果，以便对外访问且不产生额外费用。

## Implementation Decisions

- 采用B2整个信息结构及桌沿席位组合；原型切换器、模拟快照、视角入口不进入正式版。
- 使用现有HTML/CSS/JS与Go接口，权威状态、合法动作、身份、内存筹码和隐私契约继续有效。
  不从客户端计算牌型、奖项或推断缺失暗牌。结算余额为历史快照，座位余额为当前可用余额。
- 筹码使用本地原生矢量道具，近席台面摆放，中心徽记无面额，规模分段并封顶；
  0隐藏/空席无堆/断线弱化/在线待局与弃牌保留，底池与钱包独立。
- 桌面1280×720起页面与面板无滚动或折叠。正文/按钮14px起，参考英文/牌例角标12px起。
  手机参考可收起、六席按既有两列顺序、公共区及机器人在后，可纵向查看。
- 服务端增加只含公开事实的Game Announcement事件信息：稳定事件标识/顺序、确认时间、
  本局/机会标识、事件类型、席位称呼、动作原因、实际金额与全押；不含暗牌、牌序或未来随机结果。
  不用快照差分猜主动/超时动作，不遗漏一次推进跨过的阶段。
- 事件只有成功原子提交才向在线客户端发布；错误、回滚、重复请求不创建新事件。
  事件只存本进程，不增加持久化或恢复保证；重连只得到当前状态，不回放旧事件。
- 固定本地普通话女声音频覆盖六席称呼、动作、原因、阶段和数字金额；真实金额动态组合，
  不把原型固定“玩家二/十/六十六”录音作为所有实际动作。无需在线TTS或收费音频服务。
- 普通公开事件按顺序播一次，允许本人优先提醒省略旧语音；不播每张牌、逐人余额/最佳五张。
  本人故障及接管只在本人页短播，重复同类故障合并，普通同步静默。
- Action Reminder按本局与机会去重；新机会一次，剩10秒未行动一次。
  队列中的行动提醒在播放前再次验证当前机会；机会失效不播放。
  服务器计时独立于媒体播放，真人30秒、机器人既有1–8秒调度不改。
- 声音偏好存本浏览器；默认音量60%，静音包括全部提醒。播放需交互或失败时可见提示恢复。
  刷新/重连/解除静音/后台返回清旧队列，仅当前本人机会有效时读实际剩余时间，
  不足10秒不叠加十秒提醒；后台尽力播放，不承诺冻结/锁屏必达。
- 沿用免费单进程Go部署配置，不增数据库/付费资源/保活。实际上线依赖可访问的仓库及免费部署账号。

## Testing Decisions

- 用户本轮已确认：以真实页面和HTTP/WebSocket公开Interface为主；时间/牌序/随机仅通过已有
  离线构造配置控制，不添加在线作弊入口或测试私有实现。
- 真实浏览器检查满员结算、本人行动、待局/空位/断线、归零/重连设100的堆和状态，
  隐私、字号、精确金额文案、连接/提交提示、桌面一屏和手机纵向。
- 公开接口独立手算验证动作实际金额/全押/超时原因、全部快速阶段、全部赢家，
  拒绝/重试/回滚不新建播报，多个连接不泄露暗牌。
- 实际媒体加载播放与控件验证默认音量/偏好/静音、提醒优先及清队列、过期不播、
  恢复仅提醒当前机会、音频失败不禁用游戏。测试不可把人耳听感和后台必达当自动化保证。
- 沿用现有浏览器烟测、HTTP/WebSocket集成测试、可控Clock及牌序构造先例。
  按票逐个red→green，审查Standards和Spec分开，运行仓库验证与并发race检查。

## Out of Scope

数据库、登录/昵称、自由下注/加注/新扑克规则、对局持久化、跨实例共享房间、
背景音乐、收费在线语音、后台/锁屏必达、原型选择器/测试快照上线。
不将本地验收替代真实云、其他浏览器或实机验收，不创建付费资源或保活任务。
