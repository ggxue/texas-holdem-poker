# 03: 机器人真实思考与页面倒计时

Status: done
Type: task
Blocked by: None (can start immediately)
Spec: [升级规格](../spec.md) — U1、U5、U6、U10；UAC13–21、UAC03（思考部分）

**What to build:** 机器人每次合法Check／Call前由服务器实际等待1–8整数秒，页面显示“思考中”及从30秒按真实时间递减的倒计时。等待期间房间继续响应，实际动作完成后下一真人才取得完整30秒期限，失效动作不会影响结算或下一局。

## Acceptance criteria

- [x] 每次合法机器人机会独立等概率抽1–8整数秒，同一次机会只抽一次；生产等概率策略须审阅，机器人策略仍只有能Check则Check、否则Call。
- [x] UAC13：受控1秒Check机会，到期前仍为思考且未行动，到期执行一次Check并按规则推进。
- [x] UAC14：受控8秒Call机会，到期前余额及投入不变，到期足额跟10或仅剩4时Call4全押；不能Bet、Fold或按牌力改变策略。
- [x] UAC15：同轮先Check、之后真人下注而重新获得Call机会时重新独立抽样；第一次时长不复用，查询不创建新机会。
- [x] UAC16、UAC03（思考部分）：刷新、状态查询、重连、接管沿用原实际到期时间和显示依据，不重新抽样或延长，动作只执行一次；既有接管和重连设100行为保持。
- [x] UAC17：受控思考3秒，页面从30正常递减，约剩27时机器人行动；下一真人此刻开始完整30秒。刷新不从30重新显示，不能把30到0压缩为3秒，也不能让机器人等30秒或自动超时弃牌。
- [x] UAC18：思考期间查询、退出、重连及连接宽限到期照常处理，按身份裁剪并推送确认状态，不能等待思考结束才响应。
- [x] UAC19：最后一名未弃牌真人确认离房时，立即给唯一未弃牌机器人结算，不等原思考期限，旧动作失效，不重复派奖。
- [x] UAC20：结束局或下一局开始后的旧回调无效；同刻离房与思考到期时先确认离房，再仅处理仍有效动作，状态和筹码保持一致。
- [x] UAC21：机器人已全押、无行动机会的Runout、唯一未弃牌者提前胜出立即按既定流程推进，不为自动发牌或结算增加思考时间。

## Public test boundaries

- 在既有离线应用构造配置入口补充受控时长，复用固定牌序与手动时钟；通过公开命令及身份视图验证1／8秒边界、到期前不行动、到期后仅一次和原计时不变。
- 通过HTTP／WebSocket检查等待中的请求响应、真实推送、控制权、期限交错和隐私；模拟取消后的迟到事件，但只断言公开状态及余额，不断言锁布局、定时器数量或私有字段。
- 不用sleep碰随机或等待数秒；浏览器在真实页面确认正常30秒递减、思考提示和真人新期限。线上不提供选择思考时长入口。
- 可独立在当前房间容量和固定顺序下完成本票；票01、02并非逻辑前置。五身份与随机起点的组合在票07复核；已有实现不得被后续票破坏。
