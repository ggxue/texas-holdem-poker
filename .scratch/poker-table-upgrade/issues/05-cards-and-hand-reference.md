# 05: 简洁牌面、公共牌区与十类参考栏

Status: done
Type: task
Blocked by: [04：桌面与手机六座位布局及操作区](04-responsive-six-seat-table.md)
Spec: [升级规格](../spec.md) — U7、U8、U9；UAC23、UAC27（牌面与参考部分）

**What to build:** 玩家可在新牌桌中看清手牌、五个公共牌位、底池及chips余额，并随时对照十类牌型。桌面左侧常驻参考栏，手机通过“牌型参考”入口展开同样内容。

## Acceptance criteria

- [x] UAC23：参考栏按既定强到弱顺序包含完整十类牌型，每类五张简洁示例牌及项目术语的中文、英文名称，示例符合既定定义。
- [x] UAC23：手牌和公共牌统一使用可读点数与花色的简洁卡片，暗牌使用牌背；有资格者显示两张牌面或牌背，待局与空位不伪造已发手牌，身份裁剪和摊牌公开规则保持。
- [x] UAC23：五个公共牌位固定横排，未发显示空轮廓；真实局面依0、3、4、5张推进，底池始终位于其上方，不从示意图推定四张牌或示例金额。
- [x] UAC23：金额使用chips，余额配筹码图标，底池、余额与投入来自确认状态；不使用美元符号作为游戏单位。
- [x] UAC27（本票部分）：桌面1280宽参考栏位于左侧常驻；手机390宽可展开相同十类内容，公共牌五位仍保持一行，卡片与文字可读，展开／收起不阻碍操作或产生页面横向溢出。
- [x] 保留票04的固定座位、信息层级、状态栏和合法操作；若票03或06已完成，其思考显示及结果内容继续正确。

## Public test boundaries

- 浏览器通过真实开局和动作观察翻牌前至河牌、本人／他人手牌与摊牌权限，验证390／1280宽满席和空席的卡片、参考展开及操作。
- 示例预期来自既定十类牌型定义及独立牌例，不复制业务判断算法来产生预期；复用公开身份视图检查暗牌裁剪，不新增线上fixture。
- 不为静态样式或内部DOM结构建立镜像测试；按用户可见牌面、文字、布局和交互留证。
