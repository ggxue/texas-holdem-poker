## Question

用户真机截图表明手机无法在首屏看到全部对局信息，必须向下滑很长距离才能找到本人操作。
桌面 UI 已获用户确认 OK；用户要求重新执行 prototype，审阅后再推进正式更新。
手机应该保留紧凑六席全桌、优先本人信息，还是将对局与玩家详情分屏？

## Evidence and scope

- 截图1：上方品牌/控件/状态/参考入口占据空间，首屏只出现前两行大席位。
- 截图2：公共区与机器人之后才出现“你的操作”，其后还有结算与说明。
- 当前 `style.css` 的手机布局把五个玩家、公共区、机器人纵向排列，席位最少144px，
  另留40px筹码区；action-panel 在这些内容之后。桌面密度不是此次问题。
- 此前模拟手机“无横向溢出、可纵向查看”的记录仍有效，但没有验证无需长距离滚动即可行动。
  不能把旧检查当作真机操作可见性通过，也不据此自行改写已确认规格。
- 本轮仅原型：保留深红B2风格、固定席位身份、实体筹码、单底池/全押/重连100及既有声音规则。
- 展示用暂定优先级：公共牌、底池、本人手牌、当前机会与按钮首屏可见；其余详情按需查看。
  用户随后选择 A：紧凑六席常驻，并确认矮屏局部滚动、行动区常驻与详情按需展开，见[已确认规格](../spec.md)。

这不代表正式功能已实现或真机验收完成。桌面 UI 原样保留是已确定约束。
